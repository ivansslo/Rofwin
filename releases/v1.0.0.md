# Rofwin v1.0.0

Rilis awal publik **Rofwin**.

## Highlights
- Branding penuh menjadi **Rofwin**
- Optimasi default untuk **Oppo CPH1823 / Mali-G72**
- Integrasi **OBB runtime** untuk:
  - `input_controls`
  - `installable_components`
  - `wine_addons`
- Workflow GitHub Actions untuk build dan publish release
- Tema visual baru dengan gaya **tech neon hijau**
- Logo dan icon launcher baru

## Default profile untuk Oppo CPH1823
- Vulkan: **None**
- OpenGL: **VirGL**
- DX Wrapper: **WineD3D**
- Box64 preset: **Performance**
- Resolusi default: **800x600**
- Env vars low-end Mali sudah diarahkan untuk mode hemat

## Artifacts release
Release ini menyiapkan:
- APK Android arm64-v8a
- OBB runtime package
- ZIP GitHub release bundle
- SHA256 checksum
- release manifest

## Runtime OBB behavior
Rofwin akan mencoba memuat data runtime dari **OBB** terlebih dahulu, lalu fallback ke URL GitHub repo bila dibutuhkan.

## Catatan
Untuk perangkat Mali low-end, target realistis tetap aplikasi ringan, tool Windows lawas, game 2D, dan game lama. Game 3D modern tidak menjadi target utama perangkat kelas ini.
