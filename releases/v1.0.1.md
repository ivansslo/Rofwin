# Rofwin 1.0.1

Rilis restrukturisasi + perbaikan toolchain build.

## Perubahan utama
- **Project Android pindah ke root repo** — `settings.gradle.kts` (rootProject `Rofwin`) + modul `:app` (Kotlin DSL); nested project lama (`app/app`) dihapus.
- **UI modul `:app` berbasis Kotlin + Jetpack Compose** (`com.winlator`, applicationId `com.rofwin`, minSdk 26 / targetSdk 35, versionCode 101).
- **Toolchain fix**:
  - AGP `9.1.1` → **8.13.1** (versi 9.1.1 tidak tersedia di Google Maven — build pasti gagal).
  - Gradle wrapper resmi **8.14.2** kini di root (`./gradlew`).
  - CI: **JDK 17 → 21** (source/target Java 21), SDK `android-35` + `build-tools;35.0.0`.
- Script pipeline disesuaikan path baru (`app/src/main/assets`, metadata parser dukung Kotlin DSL).

## Artefak
- `Rofwin_1.0.1_arm64-v8a.apk` / `.aab` — unsigned bila secret signing tidak tersedia (lihat checklist).
- `main.101.com.rofwin.obb` — payload OBB (`input_controls`, `installable_components`, `wine_addons`).
- `rofwin-1.0.1-github-release.zip` + `SHA256SUMS.txt` + `release-manifest.json`.

## Catatan
- Payload runtime tetap diambil dari upstream `ivansslo/winlator` saat build (repo tetap ringan).
- Default tuning untuk **Oppo CPH1823 / Mali-G72** tidak berubah (lihat `docs/CPH1823-Mali-G72.md`).
